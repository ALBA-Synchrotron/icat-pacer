# ICAT-PACER

ICAT-PACER (Python Asynchronous Catalogue Entry Router) is a high-throughput, asynchronous data ingestion engine designed for the ICAT data catalogue. It is developed by the MIS section at the ALBA Synchrotron2.

The PACER provides a modern, modular, asynchronous, message-driven architecture built around RabbitMQ and Python.
